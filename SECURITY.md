# zeroswap Security

Do not open a public issue for a vulnerability that could affect funds, keys, wallets, trades, disputes, updates, or infrastructure.

The private security contact is not configured yet. Until an owner publishes and verifies that contact, mainnet release status is **NO-GO**.

Reports should include the affected version, impact, reproduction steps, and any suggested mitigation. Never send wallet seeds, private keys, passwords, or real-user personal data.

Production operators must rotate a compromised key, stop affected releases or services, preserve logs, protect in-progress trades, and follow the incident runbook in `docs/operations-mainnet.md`.
